Generate_pass.txt — تغيير باسورد الأدمن لأي عميل (البروتوكول المضمون)
====================================================================
تستخدم الملف ده كل ما عميل يطلب باسورد جديدة. نفذ الخطوات بالترتيب
ومتفوتش خطوة. الأداة المساعدة: scripts/verify-admin-hash.mjs

الخطوة 1: اتفق مع العميل على الباسورد الجديدة
---------------------------------------------
- باسورد لاتينية فقط (حروف + أرقام)، ممنوع `$` والرموز الغريبة
- مثال آمن: Sayed2026 (غيّرها لكل عميل)
- اكتبها في Notepad عندك مؤقتًا

الخطوة 2: ولّد الـ hash من فولدر المشروع
---------------------------------------------
node scripts/hash-password.mjs 'الباسورد-الجديدة'

ملحوظات إجبارية:
- علامات تنصيص مفردة '...' مش مزدوجة (المزدوجة بتكسر الباسوردات اللي فيها $)
- انسخ الناتج كله (سطر واحد يبدأ بـ pbkdf2$ وطوله ~83 حرف)

الخطوة 3: اتأكد محليًا قبل ما تلمس السحابة (أهم خطوة)
---------------------------------------------
node scripts/verify-admin-hash.mjs "الناتج-كامل" admin "الباسورد-الجديدة"

لازم تشوف:
  shape ok: true
  verify result: true
لو false: اقف ومتكملش — راجع الباسورد والنسخ من الأول.

الخطوة 4: حط القيمة في Cloudflare
---------------------------------------------
- المشروع ← Settings ← Variables ← Production
- امسح ADMIN_PASSWORD_HASH القديم واعمله من جديد بالقيمة الجديدة ← Save
- اتأكد إنه ظهر في اللستة

الخطوة 5: بناء جديد (ممنوع Retry!)
---------------------------------------------
git commit --allow-empty -m "Rotate admin password"
git push origin main
- استنى Deployments → Success على الـ commit الجديد
- السبب: زرار Retry ممكن يعيد نشر الإعدادات القديمة. البناء الجديد هو المضمون.

الخطوة 6: جرّب بنفسك أولًا
---------------------------------------------
- نافذة Incognito ← صفحة #admin ← دخول بالبيانات الجديدة ← محاولة واحدة
- لو دخل: سلّم العميل اليوزر والباسورد (واتساب، مش إيميل)
- لو رفض مرتين ورا بعض: اقف فورًا وابدأ من الخطوة 2 (ولا تحاول تالت — القفل بيشتغل بعد 5 محاولات غلط لمدة 15 دقيقة)

قواعد ذهبية (اتعلمناها بالطريقة الصعبة):
---------------------------------------------
1. ممنوع Retry بعد تغيير أسرار — دايمًا بناء جديد من push
2. ممنوع تجربة دخول متكررة (محاولتين فاشلتين = اقف)
3. محدش يلمس الداشبورد أثناء السلسلة (لا حفظ ولا نشر ولا تجربة بالتوازي)
4. الباسورد تتكتب بالإنجليزية (ENG) دايمًا، والنسخ بالماوس مش بالكيبورد
5. اليوزر admin يُكتب يدويًا حرف حرف لو اتغير قبل كده (حروف خفية بتتسرب مع النسخ من العربي)
